# SPD Website Redesign

UX research, information architecture, and prototype work for a redesign of the Society of Publication Designers website.

## Links

- [View Presentation](https://cvd9683-gif.github.io/SPD-redesign/spd-presentation.html)
- [View Case Study](https://cvd9683-gif.github.io/SPD-redesign/spd-case-study.html)
- [Presentation PDF](SPD-redesign-presentation.pdf)

## What's here

- **Presentation** is the client/demo format — 14 slides walking through the problem, research, and the redesign.
- **Case study** is the process/portfolio documentation — long-scroll editorial layout with audit, methods, personas, prioritization, sketches, and final direction.

## Structure

```
spd-presentation.html       Client-facing slide deck
spd-case-study.html         Portfolio case study
spd-competitor-analysis.html  Competitor analysis chart (embedded in case study)
assets/                     Images, videos, and other media
SPD-redesign-presentation.pdf  PDF export of the deck
```
